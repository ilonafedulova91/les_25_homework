# Django проект — Skystore (учебный проект)

## Описание проекта

Данный проект создан в рамках изучения Django.  
Он представляет собой простой веб-сайт с двумя страницами:

- Главная страница (каталог)
- Страница контактов с формой обратной связи

Проект демонстрирует основы работы Django: маршрутизацию, представления (views), шаблоны и обработку форм.

---

##  Используемые технологии

- Python 3.12+
- Django 6.x
- HTML5
- Bootstrap 5 (через CDN)
- SQLite (по умолчанию Django)

---

## Запуск проекта

### 1. Клонирование репозитория

```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd <НАЗВАНИЕ_ПАПКИ>
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
```

### 3. Активация окружения

Windows:

```bash
venv\Scripts\activate
```

Linux/macOS:

```bash
source venv/bin/activate
```

### 4. Установка зависимостей

```bash
pip install django
```

(или pip install -r requirements.txt, если он есть)

### 5. Запуск сервера

```bash
python manage.py runserver
```
После запуска проект будет доступен по адресу:

```bash
http://127.0.0.1:8000/
```

## Функционал

### Главная страница
* Отображает информацию о проекте
* Использует Bootstrap для оформления

### Контакты
* Форма обратной связи
* Обработка POST-запроса
* Вывод сообщения об успешной отправке

### Форма обратной связи

Поля формы:
* Имя
* Телефон
* Сообщение

После отправки данных:

* данные обрабатываются в views.py
* выводится сообщение об успешной отправке

## Цель проекта
* Освоить базовую структуру Django-проекта
* Научиться работать с маршрутами (urls)
* Понять принцип работы views (контроллеров)
* Освоить шаблоны (templates)
* Научиться обрабатывать формы (POST-запросы)
